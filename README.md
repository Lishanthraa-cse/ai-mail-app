> Compose emails, search messages, apply filters, and navigate - all through conversation.


## 📖 Overview

This is a fully functional email web application with an integrated AI assistant that can **control the UI programmatically**. Unlike traditional chatbots that just answer questions, this assistant:

- **Opens compose forms** and fills in email fields visibly
- **Searches and filters** emails updating the inbox in real-time
- **Navigates between views** (Inbox, Sent, Email Detail)
- **Understands context** (knows which email you're reading)
- **Executes actions** when instructed through natural language

The assistant is a **co-pilot that drives the interface**, not just a chatbot.

## ✨ Key Features

### 📧 Mail Client
- ✅ **Inbox** - List of received emails with sender, subject, preview, and date
- ✅ **Sent** - List of sent emails
- ✅ **Compose** - Write and send emails with To, Subject, and Body
- ✅ **Email Detail** - Read full email content

### 🤖 AI Assistant Capabilities
| Command Type | Example | What Happens |
|-------------|---------|--------------|
| **Compose & Send** | "Send an email to john@example.com with subject 'Meeting' and body 'Let's meet at 3pm'" | Compose opens, fields fill visibly |
| **Search & Display** | "Show me emails from the last 10 days" | Inbox updates with filtered results |
| **Navigate & Open** | "Open the latest email from David" | Navigates to specific email detail |
| **Context Awareness** | "Reply to this" (while reading an email) | Pre-fills reply with email context |
| **Filters** | "Show only unread emails from this week" | Inbox filters accordingly |

### ⚡ Additional Features
- **Real-Time Mail Sync** - New emails appear without manual refresh
- **Dark Mode** - Toggle between light and dark themes
- **Email Filters** - By date, sender, keyword, read/unread status
- **Human-in-the-loop** - Assistant asks for confirmation before sending
